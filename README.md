## 🌟 About the Project

**Returns** is a browser-based dashboard for exploring Indian mutual funds, comparing historical returns, visualizing hypothetical investment growth, and learning common mutual-fund concepts.

> ⚠️ **Important financial note**
>
> This is an educational portfolio project—not investment advice or a verified real-time financial data source. Some values in `data.js` or the HTML may be sample/static values. API-backed NAV information depends on the external service, internet access, and browser CORS support. Always verify figures using official sources before making financial decisions.

---

## ✨ Features at a Glance

| Feature | What you can do |
|:--|:--|
| 🔎 **Fund Screener** | Search, filter, and sort mutual-fund schemes |
| ⚖️ **Fund Comparison** | Compare up to four schemes side by side |
| 📅 **Historical Returns** | Explore 1Y, 3Y, 5Y, and 10Y return horizons where data is available |
| 📊 **Investment Charts** | Visualize hypothetical SIP and lump-sum growth |
| 🧮 **SIP Calculator** | Estimate SIP and step-up SIP outcomes |
| 🧾 **Tax Estimator** | Explore illustrative capital-gains tax scenarios |
| 🏢 **Fund Houses** | Browse fund houses and available portfolio information |
| 🔗 **Holdings Overlap** | Examine stock overlap between selected schemes |
| 🌐 **Scheme Lookup** | Search the wider scheme database using MFAPI, subject to availability |
| 📚 **Learning Corner** | Read the built-in mutual-fund glossary and educational guide |
| 📱 **Responsive UI** | Use the dashboard on phone and laptop-sized screens |
| 🌗 **Themes** | Switch between dark and light themes |

## 🚀 Run It on Your Computer

### 1️⃣ Get the project

Download this repository as a ZIP, or clone it:

```bash
git clone https://github.com/YOUR-GITHUB-USERNAME/returns-mutual-fund-analyzer.git
```

### 2️⃣ Open the folder

Open the project folder in **Visual Studio Code**.

### 3️⃣ Launch the website

- **Quick option:** Open `index.html` in your browser.
- **Recommended option:** Use the **Live Server** extension in VS Code.

### 4️⃣ Keep the files together

Make sure `index.html`, `styles.css`, `data.js`, and `app.js` remain in the same folder.

> 💡 Some lookup features and remote fonts need an internet connection. Static parts of the interface may still display offline, but API-backed features may not work.
